SETUP
1. Extract index.html, styles.css and script.js into your website folder.
2. Put your actual image files in that SAME folder with these exact names:
   Designer.png
   hoagie.jpg
   store front.jpg
   bagels.jfif
3. Open index.html in a browser, or upload all seven files to your static host.

IMPORTANT
The original food/storefront files were not attached to this conversation.
